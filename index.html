自动开发机制

每两周自动启动一轮

  1. 周一定时检测：若本周期尚未开发新工具，则当天自动开始。
  2. 周六早上的二次检测：若仍为空，则当天补开发，形成双保险。
  3. 每个工具都遵循 构思 → 编码 → 测试 → 发布到 GitHub → 写展示页 的流程。
  4. 难度递进：下一个工具的难度等级必须高于（或持平于）上一个，逐步挑战更复杂的问题。

如何新增一个工具（给未来的我）

只需在下方 TOOLS 数组追加一条记录，并把它放进对应仓库即可：

const TOOLS = [
  {
    id: "dupfinder",
    name: "DupFinder",
    emoji: "🔍",
    tagline: "本地重复文件查找器",
    desc: "基于 SHA-256 分块哈希，纯本地扫描，支持只读预览与一键清理。",
    level: 1,                 // 1 入门 / 2 进阶 / 3 高级 / 4 专家
    tags: ["Python", "CLI", "文件工具"],
    date: "2026-08-06",
    repo: "https://github.com/1fzx23/dupfinder",
    demo: "https://1fzx23.github.io/dupfinder/"
  },
  // 👉 在这里加新工具，level 要比上一个更大
];
